# StudentTask-AssignmentTracker
A web-based Student Task and Assignment Tracker that helps students organize assignments, manage deadlines, track task progress, and stay productive.

This web follows Agile Software Development principles, with clearly defined team roles such as Product Manager, Project Manager, Scrum Master, and Developers. The aim is to apply software engineering concepts such as requirement analysis, project planning, Agile methodology, system design, development, testing, and documentation to develop a practical solution for students.

# 📍Problem Statement

Students often have to manage multiple assignments, projects, tests, and deadlines simultaneously. Without a proper system for organizing these activities, students may forget deadlines, lose track of their progress, or have difficulty prioritizing tasks.

The proposed system provides a centralized platform where students can create, organize, prioritize, monitor, and complete their academic tasks.

# 📍Objectives
- To provide a centralized platform for managing academic tasks and assignments.
- To help students keep track of deadlines.
- To allow students to prioritize tasks based on importance.
- To monitor task completion and progress.
- To improve organization and time management.
- To apply software engineering and Agile Development practices.

# ✨Key Features
- Add, edit, and delete tasks
- Assignment and task Management
- Deadline Tracking
- Task priority management
- Task status tracking
- Progress monitoring
- Organized task dashboard
- Upcoming deadline tracking
